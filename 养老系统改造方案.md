# 医疗系统到养老院管理系统 代码修改方案

基于现有毕业设计系统（Spring Boot + Vue3 + MySQL）进行领域迁移改造

---

## 一、核心概念映射

| 医疗系统 | 养老院系统 | 说明 |
|---------|-----------|------|
| 患者 Patient | 入住老人 Resident | 实体替换 |
| 科室 Department | 护理区 Zone | 自理区/半护区/全护区/失智区 |
| 住院号 | 入住编号 | 格式改为 YZ + 年份 + 序号 |
| 主治医生 | 照护主管 | 角色名称变更 |
| 分管护士 | 护理员 | 职责更偏向生活照料 |
| 入院登记 | 入住登记 | 业务含义变化 |
| 出院 | 离院/迁出 | 业务场景变化 |
| 预约 Appointment | 家属探访预约 | 功能复用 |
| 检验结果 LabResults | 健康检查记录 | 体检而非化验 |

#### 新建 HealthCheckupController.java

文件路径：backend/src/main/java/com/graduation/medical/controller/HealthCheckupController.java

```java
package com.graduation.medical.controller;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.graduation.medical.common.Result;
import com.graduation.medical.entity.HealthCheckup;
import com.graduation.medical.mapper.HealthCheckupMapper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import java.math.BigDecimal;

@RestController
@RequestMapping("/api/health-checkup")
@CrossOrigin
public class HealthCheckupController {

    @Autowired
    private HealthCheckupMapper healthCheckupMapper;

    @GetMapping("/list")
    public Result<?> list(@RequestParam(defaultValue = "1") Integer current,
                          @RequestParam(defaultValue = "20") Integer size,
                          @RequestParam(required = false) Long residentId,
                          @RequestParam(required = false) String residentName) {
        Page<HealthCheckup> page = new Page<>(current, size);
        LambdaQueryWrapper<HealthCheckup> wrapper = new LambdaQueryWrapper<>();
        if (residentId != null) wrapper.eq(HealthCheckup::getResidentId, residentId);
        if (residentName != null) wrapper.like(HealthCheckup::getResidentName, residentName);
        wrapper.orderByDesc(HealthCheckup::getCheckDate);
        return Result.success(healthCheckupMapper.selectPage(page, wrapper));
    }

    @PostMapping
    public Result<?> add(@RequestBody HealthCheckup checkup) {
        // 自动计算BMI = 体重 / 身高^2
        if (checkup.getHeight() != null && checkup.getWeight() != null
                && checkup.getHeight().compareTo(BigDecimal.ZERO) > 0) {
            BigDecimal bmi = checkup.getWeight()
                    .divide(checkup.getHeight().multiply(checkup.getHeight())
                            .divide(new BigDecimal("10000"), 4, BigDecimal.ROUND_HALF_UP),
                            2, BigDecimal.ROUND_HALF_UP);
            checkup.setBmi(bmi);
        }
        healthCheckupMapper.insert(checkup);
        return Result.success("健康检查记录保存成功");
    }

    @PutMapping
    public Result<?> update(@RequestBody HealthCheckup checkup) {
        healthCheckupMapper.updateById(checkup);
        return Result.success("更新成功");
    }

    @DeleteMapping("/{id}")
    public Result<?> delete(@PathVariable Long id) {
        healthCheckupMapper.deleteById(id);
        return Result.success("删除成功");
    }
}
```

#### 新建 FamilyController.java

```java
package com.graduation.medical.controller;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.graduation.medical.common.Result;
import com.graduation.medical.entity.FamilyMember;
import com.graduation.medical.mapper.FamilyMemberMapper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import java.util.*;

@RestController
@RequestMapping("/api/family")
@CrossOrigin
public class FamilyController {

    @Autowired
    private FamilyMemberMapper familyMemberMapper;

    @GetMapping("/list/{residentId}")
    public Result<?> list(@PathVariable Long residentId) {
        LambdaQueryWrapper<FamilyMember> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(FamilyMember::getResidentId, residentId)
               .orderByDesc(FamilyMember::getIsPrimary);
        return Result.success(familyMemberMapper.selectList(wrapper));
    }

    @PostMapping
    public Result<?> add(@RequestBody FamilyMember member) {
        if (member.getIsPrimary() != null && member.getIsPrimary() == 1) {
            LambdaQueryWrapper<FamilyMember> wrapper = new LambdaQueryWrapper<>();
            wrapper.eq(FamilyMember::getResidentId, member.getResidentId())
                   .eq(FamilyMember::getIsPrimary, 1);
            List<FamilyMember> primaries = familyMemberMapper.selectList(wrapper);
            for (FamilyMember p : primaries) {
                p.setIsPrimary(0);
                familyMemberMapper.updateById(p);
            }
        }
        familyMemberMapper.insert(member);
        return Result.success("添加成功");
    }

    @PutMapping
    public Result<?> update(@RequestBody FamilyMember member) {
        familyMemberMapper.updateById(member);
        return Result.success("更新成功");
    }

    @DeleteMapping("/{id}")
    public Result<?> delete(@PathVariable Long id) {
        familyMemberMapper.deleteById(id);
        return Result.success("删除成功");
    }
}
```
